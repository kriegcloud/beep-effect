# Dependency refresh after repository recovery

This change carries the dependency updates that remained unpublished when
repository recovery PR #1928 merged. It preserves the operator's supplied
updates and the compatibility holds recorded in `syncpack.config.ts`.

The update includes the Next canary family, XState alpha family, Storybook,
MUI X, OpenTelemetry exporters and SDKs, DuckDB, Turbo, Oxlint and its plugin,
React type packages, and the selected workspace dependencies. Related packages
move together. The lockfile is generated by Bun 1.4.3, and a frozen installation
passes with the updated declarations.

## Compatibility changes

XState Effect alpha.9 still exposes an unnameable private action brand when an
application exports its machine. The alpha.8 patch is replaced with its alpha.9
equivalent. The existing declaration-emit regression test passes without
changing its machine fixture or weakening its TS4023 assertion.

The DuckDB update changes the Windows sidecar version and integrity together.
The SHA512 value was checked against the published artifact, and the package
test continues to reject modified sidecar bytes.

OpenTelemetry's new trace exporter accepts a different readable-span contract
from the separately versioned trace SDK. The ai-metrics adapter derives its
private input type from the exporter's public `export` method. Its runtime
payload construction is unchanged. Loopback exporter tests cover batching,
resource routing and an HTTP 415 failure.

The [patch audit](dependency-patch-audit-2026-10-20.md) records why the Effect,
Node platform, Drizzle and ONNX patches remain necessary. Their registrations,
overrides and regression tests remain paired.

## Retained versions

The existing compatibility holds remain in force, including the Lexical
composer migration, Bun/jsdom compatibility and compiler diagnostic promotion.
The infrastructure TypeScript 6 selection and the PGlite 0.4.6 compatibility-test
alias also remain intentional. Updating that alias would remove the old-data
compatibility proof.

Ink remains at 7.1.1. Ink 8 removes the zero-width separator used to neutralize
workflow commands in terminal output. Existing security assertions exposed the
regression, so this change adds an update hold rather than weakening them.

Stately tools stays at 0.14.3. The inspected 0.15 release depended on
`@statelyai/model-testing@0.2.0`, which was unavailable from the public registry.
Recheck that dependency before attempting the upgrade again.

Fallow stays at 3.33.1 pending [the analyzer promotion audit in
#1932](https://github.com/beep-effect/beep-effect/issues/1932). Version 3.34
corrects single-star entry glob semantics and exposes 61 findings in existing
code. The same checkout reports zero with 3.33.1. Promoting the new analyzer
requires checking each public API and generated entry, rather than widening
entry globs or replacing the zero dead-code baseline. The existing analyzer
and its enforced gates remain active.

Syncpack's updater also applies its configured release-age policy. A successful
catalog update does not claim that every newly published package or workspace
dependency was selected. The manifests and lockfile record the actual versions;
the hold register records deliberate exceptions.
