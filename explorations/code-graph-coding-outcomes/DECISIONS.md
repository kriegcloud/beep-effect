## 2026-10-09 — Native child capability and documented update hooks

The operator requires usable documented integrations, including update hooks.
Preserve UA's official update hooks for productive runs. Expose the same native
child capability to every arm within a coding harness, with the same coding
model/medium effort, inherited filesystem/network/assigned-tool boundaries and
shared resource limit. This avoids making a child-dependent integration appear
available while disabling its execution path. The fixed-answer readiness probe
may disable auto-update only when that limitation is stated. A hook requiring
an incompatible model, billing route or escaping child context remains blocked
until compatibility is proved; unsupported is an explicit result.

Observed host usage is not automatically whole-invocation usage. Retain child
counts and observed child counters when available; unknown child usage stays
null. Disabling a native delegation tool alone does not prove a shell cannot
invoke an available CLI. Final controls must record actual authority and coverage.
Reversal: disable the experimental profile and remove only its owned state;
production agent wiring is unchanged. This decision is pending profile proof,
not authorization for scored runs.

## 2026-10-09 — Source history, model provenance and executed-source identity

Every coding arm should receive the same ordinary Git ancestor history ending
at the frozen base, with no later commits, other branch tips, remotes or trial
history. This preserves a fair ordinary source route while full-depth tools use
blame/cochange history. Seed independent repositories from an ancestor-only
base bundle; never mount the production object store writable. Retain the base
bundle and every trial commit/diff. This replaces the proposed depth-one seed
before any coding pilot; the bundle and resource proof are still pending.

Record model/effort provenance by layer: exact documented invocation/config,
native selected-model/turn context, and provider response where exposed. Reject
contradictory observed identities; do not infer identity from token counters.
An absent provider effort field is null, not a contradiction or an attestation.
Codex productive attempts retain native session context in a fresh private home
instead of using ephemeral mode. No attempt may resume another arm's context.
Unknown child usage or identity coverage remains explicit; confirmed off-pin
children violate controls. Model identifiers, effort and parent/child coverage
must remain separate from deterministic code outcome fields.

Acceptance runs against a fresh contained reconstruction of the retained final
commit, with only frozen runtime/build artifacts attached. A clean Git status is
insufficient: ignored files can affect execution without entering a commit.
Original worktrees and ignored-file inventory remain diagnostic artifacts, not
passing-proof inputs. Reversal for all three decisions is removal of owned
experimental profiles/reconstructions after immutable receipts are retained.
## 2026-10-09 — Freeze existing unsigned runtime bytes explicitly

The evaluator's minimal Nix closure separates public cache artifacts from the
already installed Determinate runtime. The public development-shell and input
sources retain native signature or content-address verification. The installed
runtime has 64 pre-existing paths without cache signatures; its installer origin
does not establish a cache signature. An owned shell environment is also local.

For those enumerated local paths only, permit a local copy without cache-signature
checking, with independently verified native NAR hashes and binary hashes before
and after copying. This admits no unsigned network download and asserts no
upstream signature. Reject any path outside the allowlist or any content drift.
Keep the rejected strict-copy attempt. Do not self-sign observed bytes and present
that as upstream authentication. This is a supplemental evaluator runtime input;
the original toolchain freeze remains immutable and trial admission is pending.

The reason is to freeze the existing runtime independently of host garbage
collection without triggering source builds or substituting a new runtime. The
reversal is to discard only the owned supplemental snapshot and its candidate
profile, retaining the receipt; no host store, daemon or production config changes.
