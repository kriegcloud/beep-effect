# Research

## 2026-10-09 — External landscape

The [operator contract](CAPTURE.md) asks whether graph assistance improves complete Beep coding outcomes. A UI demonstration and vendor retrieval rankings cannot establish that result. The original video claims and whole-file-read savings counter remain motivation to source-check, not observed session savings. The [source ledger](research/SOURCES.md) records each cited public study and its current mining status.

The [dated eligibility receipt](research/ELIGIBILITY.md) and fixture receipts establish twelve graph configurations plus a no-graph control. [Readiness](research/READINESS.md) imports their exact frozen identities by digest, distinguishes source pins from published artifacts, and records exclusions. Additional eligible candidates were Code-Graph-RAG, fallow and Understand Anything; Serena LSP and JetBrains remain separate configurations of one tool. Full expensive Beep ingestion is still pending for every tool.

Methodological leads include adoption canaries, known-correct/wrong path parsing, retained raw failures, stale-index provenance and cache-aware counterbalancing. These are prospective requirements from the operator contract; benchmark bodies have not yet been mined into this packet or used to rank tools. No external code is ported.

## 2026-10-09 — In-repo capability inventory

[Runner reuse](research/RUNNER-REUSE.md) identifies `@beep/repo-ai-metrics` BenchmarkRun/scorecard, config snapshots, content-free telemetry and protected archive seams; `@beep/repo-cli` AgentEffectiveness controls/variants/measurements, deterministic scorer/comparison, StepExec, resource scope, worktree and Yeet provenance. Live lane searches reconfirmed the named BenchmarkRun and AgentConvention schema exports at the documented paths. The broader staged audit was performed at an earlier main snapshot and must be revalidated before implementation claims on the final trial base.

NOT FOUND in that audit: a complete typed three-harness disposable executor, provider-native observed token/cache/adoption parsers including Grok, and the experimental matrix receipt/projection. Extend existing tooling rather than creating a parallel generic framework. Repo-operational code belongs under `packages/tooling` per [architecture family routing](../../standards/architecture/07-non-slice-families.md).

[Task readiness](research/TASK-READINESS.md) retains all three requested existing goals conditionally. Their specs remain normative; provisional ownership and prerequisite evidence does not freeze task prompts, hidden checks or a common green base.

## 2026-10-09 — Constraints discovered

Readiness is passed, yet exact-common-base full Yeet, task P0/acceptance, end-to-end runner pilot, full documented ingestion and protocol freeze remain distinct gates. Hooks, copied local guidance, credentials, cached graphs, generated wiki pages, run state and IDE project roots can contaminate arms. The experiment needs a no-copy isolated worktree profile and exact-root JetBrains gates. Unavailable usage/cost/resource fields remain null. [Decisions](DECISIONS.md) bind the local exemption and expiry; [protocol](research/PROTOCOL.md) is explicitly a draft.
