# Experiment protocol — DRAFT, NOT FROZEN

As of 2026-10-09 only the exact toolchain is frozen. The [machine-readable draft](../ops/protocol-draft.json) is an admission checklist and desired control contract, not authorization to start scored cells. The [full operator prompt](../CAPTURE.md) remains normative wherever this draft is incomplete. Freeze the common green source, task briefs, acceptance, and pilot controls before any coding pilot. After the end-to-end pilot and full ingestion quality gates, freeze the final integration/index/order/limits/rerun/judge identities before scored runs; any counted pilot must be rerun under those final controls.

## Outcomes and populations

Three existing goal tasks, twelve graph configurations plus no graph, three coding models: GPT 6.1 Sol medium, Claude Opus 5.5 medium, Grok 4.7 medium. Exact identifiers `gpt-6.1-sol`, `claude-opus-5-5`, `grok-4.7`; actual Grok native usage may identify the build model separately and must be preserved. Different model/harness pairs are separate causal strata. Compare each tool against no graph within the same task/model, then paired Serena LSP/JetBrains; do not collapse backends or claim significance from one run per cell.

## Launch controls and isolation

All arms for a task use the same pinned main commit **and** content SHA-256, identical standalone brief/non-graph law guidance/acceptance/resource/environment controls. Fresh isolated worktrees and contexts receive no evaluation labels, other arms, prior results or hidden reuse/acceptance oracles. Agents may use only ordinary assigned-tool guidance. No-graph receives no graph; treatment receives only its selected graph tool. Effect references/docs are the same ordinary read-only route for all. No Graft-only federated Effect graph. Scored graph corpus is the frozen Beep repository; JetBrains dependency-index capability is permitted as a labeled practical difference with separate Beep-only diagnostics.

Isolate auth scope, hooks, skills, instruction files, auto-upkeep, indexes/wiki pages, caches, generated output and run state. Block push/remote branch/PR/merge/message actions by trial authority; local commits are mandatory deliverables. Retain every attempt/commit/diff. Tool identity freeze includes repo/version/source or distribution pin, runtime/dependency-lock hashes, config/hook/instruction digests and observed native integration. Never upgrade during scored runs.

## Task/base/ingestion gates

Recheck ownership and normative goal state, resolve P0 and freeze complete bounded briefs/executable acceptance plus protected oracle digests. Replace genuinely unready tasks with another unclaimed ready existing goal before freeze; no mid-matrix change. Prove common base full `bun run beep yeet verify` green on its exact commit. Attribute inherited reds and repair/choose a common green snapshot before trials.

Ingest every tool to its full expensive documented readiness depth with source-commit coverage, failed-file count, index health and correct/wrong canaries. Record ingestion model/config/version/route, wall/CPU/RAM/disk, usage and refresh cost, then immutable or resettable per-run snapshots. Incumbent Opus-built Graft deep copy catches up incrementally; preserve production cache and historical model/cost. Muse Spark 1.3 minimal subscription route gets receipt-backed compatibility/quality pilots before bulk. No silent paid endpoint or reduced depth.

Serena JetBrains startup must select that backend, open the exact trial worktree in WebStorm, wait indexReady, verify dashboard/backend and a JetBrains-specific canary. Serialize roots or prove isolated IDE projects; never serve another arm's symbols. Record IDE warm/cache/sync/setup costs. Separate source-checked dependency search/hierarchy/refactoring/debugger availability probes expose capability without forcing scored agent adoption. Unsupported model/backend cells retain evidence; never substitute LSP.

## Measurement, proof and reruns

Native observed input/output/cache read/write, requests/turns, tool invocation/adoption, elapsed, interventions/retries, task-check results, defects and final commit are separate fields; unavailable is null. Retain complete private raw outputs and public sanitized immutable digest references. Each parser needs known-correct and known-wrong responses. No invocation is an adoption result, not proof of poor graph quality. Record stale-index/false-confidence/path/fidelity/precision-recall/footprint diagnostics separately.

Passing requires task acceptance and **full** `bun run beep yeet verify` on the exact final local commit with command/tier/base/head/exit/receipt/provenance. Missing, focused-only, interrupted or red full proof cannot pass. Neither grade nor static scorer waives failure. Common-base and final-head proof are distinct. The evaluator must pin the native auxiliary base ref to the trusted trial BASE in independent Git metadata, protect that ref and its resolution configuration during verification, and require matching pre/post and finalization evidence. Candidate refs must not redefine the base. A nonempty BASE-to-FINAL canary and legitimate Git-operation probes qualify this control before final freeze. Winner delivery later requires hosted CI/review/ordinary Yeet.

End-to-end pilot: one no-graph and one graph cell prove isolation, real accounting/adoption, exact-head full proof, blinded packaging and interruption/resume. Fix and lock instrumentation before matrix; replay counted pilots under final controls. Counterbalanced order, seeds/resource bounds, timeout, retry eligibility/attempt cap and interruption/resume rules are **pending preregistration**; all failures/aborts remain visible. On quota/unexpected cost checkpoint and report rather than silently rerun or change models/accounts/controls.

## Review and selection

Deterministic gates first. Fresh blinded panel: GPT 6 Astra, Claude Opus 5.5, Grok 4.7; exact reviewer IDs/provenance and any availability-driven substitution recorded before judging candidates. Inspect diff/relevant code/doctrine with labels hidden where practical. Operator grades top 3 full-verify-passing finalists per task plus close calls. Anchored 1–5 grades separately for law compliance, Effect, reuse and maintainability:1 material defect;2 significant repair;3 acceptable;4 strong/minor issues;5 exemplary. Require brief file/diff-cited rationale and separate low/medium/high certainty. Preserve disagreement; no opaque confidence total.

Select pass rate and quality/reuse first, then observed time/tokens and setup/upkeep, reporting distributions/failed/unknown/unsupported cells. If no arm passes for a task, report no winner and preserve remediation artifacts. Advance the best qualifying local implementation per task toward its own ordinary PR without pretending that local proof is hosted readiness or tool adoption.
