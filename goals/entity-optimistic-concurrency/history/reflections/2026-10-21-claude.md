# Reflection — entity-optimistic-concurrency (2026-10-21, claude)

## Summary

PR #1941 makes `rowVersion` the shared optimistic-concurrency token
(`Pg.version()` plus `DEFAULT 1`), guards every by-id entity UPDATE with a
compare-and-increment, and reports typed per-port version conflicts. Every
write path in the inventory has a stale-write or bump test, and the race tests
were mutation-checked.

## Tooling experience

- **Worked:** `turbo run check test --filter='...@beep/shared-domain'` found
  every downstream test pinning the old variant shape in one pass (188 tasks).
  `drizzle-kit generate` produced exactly the 26 `SET DEFAULT 1` statements.
  `yeet reply` handled both review threads cleanly.
- **Didn't:** PGlite fibers could not interleave a read-modify-write. The first
  dependents typecheck in a fresh worktree reported stale-dist errors.
- **Frustrating:** cheap-gates attribution took a pass per gate (effect-vitest,
  schema-first, fallow complexity from `?? 1` branches, goals phase-status
  literal, observability catalog). A gitignored 2026-09-09 residue made the
  markdown imports gate red locally only.
- **Wished existed:** a shared race harness and a schema-catalog gate in
  cheap-gates.

## Implementation improvement opportunities

- Client-carried expected versions on update commands (F1).
- A soft-delete decision for `ProviderInstance.remove` (F2).
- `agents_provider_instance` belongs under a db-admin migration; until then
  its adapter writes the first version explicitly.

## Goal & prompt critique

- The brief's route analysis was accurate, but one premise was off: a single
  transform-configured client would share Drizzle's transaction scope. The
  real blocker for `makeRepository` is that it refuses `columnName` overrides.
  The SqlModel session's note corrected D2. Propose adding to the brief:
  "check `makeRepository` against the kit's `columnName` overrides".
- "Every by-id update path" should say "and every predicate or single-column
  UPDATE": the bump-only sites were half the inventory.

## TODOs worth codifying

- Shared PgClient race harness in `@beep/test-utils`.
- `lint:schema-catalog` in cheap-gates.
- A lint that every entity-table UPDATE sets `rowVersion`.

## Lessons (confidence-tiered)

- **HIGH — Critical:** prove a concurrency guard with an injected interleaving
  and a mutation check, never with "concurrent" fibers on one session. The
  fiber test passed without exercising the race.
- **HIGH — Critical:** before relying on a new column default, confirm a
  migration provisions it for every table that uses the kit. One table was
  outside db-admin.
- **MEDIUM — Best practice:** grep production callers of a repository port
  before tightening its contract. The VaultSyncEngine revive loop would have
  self-conflicted on its own stale snapshot.
- **LOW — Consideration:** `x ?? default` inside a long test callback can trip
  fallow's CRAP threshold; a named helper keeps the branch out of the body.
