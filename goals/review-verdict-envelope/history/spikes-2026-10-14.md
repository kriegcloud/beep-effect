# P0 spike report (2026-10-14)

Surface: the Claude desktop app's Code tab on the operator's Linux workstation, Claude Code 2.1.295.
The spike was a throwaway dev mod hot-loaded into one session (not product code, not committed).
All test content was public: a sample claim line, and a public research paper uploaded to a scratch
Box folder.

## One-app answer

The attorney lives in **Outlook and Word**. The operator's direction is to move him to Claude.
The Claude review pane stays the target; see the Decision Log in `SPEC.md`.

## Mod-authoring notes for `practice-claude-mod` P1b

- `$.state.set` (and `update`) is denied inside `ui.render`. Write only from handlers or other
  events.
- Every function that receives `$` must be declared at the top level of the module.
- A press handler's failure is silent unless the handler records first. A `command.run` hook that
  returns `context` is a reliable way to report results back to the agent.
