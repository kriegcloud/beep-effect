## Public Summary

A small compressed DOCX admitted through Box can expand into oversized XML before the response text cap is applied in the shared gateway process.

## Current-HEAD Analysis

Cloud evidence confirms compressed-byte admission and post-extraction truncation; auxiliary XML amplification is reproduced, with production Mammoth exhaustion unmeasured. Limits are drafted at the shared driver boundary, covering direct callers too.

Validation, Evidence, and Attack-path analysis were read from the authenticated
Cloud detail on 2026-10-20. The private capture is ignored under
`raw/CSF-003-cloud-detail.txt`; signed artifact links are omitted.
This is source analysis, not a passing runtime proof. Baseline: `8086a42233`.

## Draft Remediation

Stream ZIP entries in small compressed chunks; bound actual total expanded bytes, entry count, XML nodes and depth; reject DTDs. Rebuild a stored ZIP from validated entries before Mammoth sees it. Resolve XML relationship targets, use Mammoth-compatible UTF-8/BOM handling without transcoding, count attributes and reject ZIP aliases. Author malicious metadata, aggregate budgets, custom XML, unsupported UTF-16, valid-document and input-preservation regressions.
