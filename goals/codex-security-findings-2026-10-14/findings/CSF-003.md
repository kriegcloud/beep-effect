# CSF-003: Draft edits can bypass the outbox send expectation guard

- Severity: Medium
- Codex ID: `commit:91a88af887488191a7bae407f0db18c8`
- Source commit: `fa90e642f1b572e5cd64c4e0b064f4d7d2a86697`
- Owner: M365 outbox draft sending
- Status: confirmed; repair implemented

## Public Summary

The outbox checks the recipients, subject and attachment hashes of a mutable
Graph draft, then calls the send-draft action with only its id. A separate
principal with draft-edit permission can change the message after the check
and before that action, causing mail to be sent outside the expectation.

## Current-HEAD Validation

Verdict: confirmed at current HEAD. The send action had no documented version
precondition or immutable request body; the implementation read the draft and
sent it in separate Graph operations.

## Remediation

Fail closed. `m365_outbox_send_draft` still checks and records mismatches, but
returns `version-unbound` for a matching draft without calling Graph's send
action. Update tool instructions and operator documentation; a person can
review and send the prepared draft in Outlook. Restore automated sending only
with a documented version-bound action or an immutable message request and
focused concurrency proof.
