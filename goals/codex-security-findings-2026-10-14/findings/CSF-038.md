# CSF-038: Font metadata can inject executable generated TypeScript

- Severity: Informational
- Codex ID: `commit:c42eb93a601081919e02de0170c74752`
- Source commit: `ade1def89b2a6acdeb75e2480c070e0bf8defc4d`
- Owner: Technical drawing glyph generator
- Status: confirmed; repair implemented

## Public Summary

The glyph generator placed untrusted font name-table version text directly inside a generated TypeScript block comment. A crafted version could close the comment and insert executable code when the module is imported.

## Current-HEAD Validation

Verdict: confirmed at current HEAD. Current HEAD interpolated a parsed font version into the source comment without escaping. Custom font paths are supported by the generator.

## Remediation

Emit only SHA-256 digests in the generated provenance comment and remove the unnecessary version parser. Regenerate the committed glyph module from the default fonts.

Changed files:

- `packages/foundation/capability/technical-drawing/scripts/generate-label-glyphs.ts`
- `packages/foundation/capability/technical-drawing/src/internal/LabelGlyphs.ts`

- `bun run generate` passed.
