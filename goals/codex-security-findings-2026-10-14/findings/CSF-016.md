# CSF-016: Publisher PDF discovery bypasses internal\-source restrictions

- Severity: Low
- Codex ID: `commit:d0dac0dd3c10819188d81129e88a841b`
- Source commit: `e89fab0c8e0bae8759aa239619cab256fdb02682`
- Owner: research library paper acquisition
- Status: confirmed; repair implemented

## Public Summary

An untrusted publisher landing page could supply a PDF locator pointing to an
internal HTTP service. Acquisition requested that follow-up URL before PDF
validation, bypassing the original citation's internal-source classification.

## Current-HEAD Validation

Verdict: confirmed at current HEAD. The metadata candidate check allowed
internal destinations and the HTTP client made a second GET before content
validation; redirects were not explicitly disabled for the request.

## Remediation

Retain publisher landing pages as incomplete evidence without automatically
following their HTML locators. Disable automatic HTTP redirects for direct
paper requests. Operators may provide a vetted direct PDF URL as its own
source. The acquisition regression includes an internal metadata URL and
observes only the original request.
