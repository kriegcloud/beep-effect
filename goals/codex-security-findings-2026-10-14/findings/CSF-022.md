# CSF-022: Quadratic overlap enumeration enables drawing\-spec denial of service

- Severity: Informational
- Codex ID: `commit:191fef10ce6c81919e844657645ffce0`
- Source commit: `01d2c6c35f1dbdef5716d5b3efc5f1233e4a7a35`
- Owner: OCCT overlap counting and model schema
- Status: confirmed; repair implemented

## Public Summary

The overlap counter eagerly constructed every unordered pair of model parts
before discarding disjoint boxes. A supplied model with many parts could
exhaust memory or block the local drawing command.

## Current-HEAD Validation

Verdict: confirmed at current HEAD. The prior `A.flatMap` generated
`n(n-1)/2` pair tuples and the `ModelSpec` schema had no maximum part count.

## Remediation

Count overlaps incrementally without retaining pair tuples. Limit a model to
256 parts at schema decoding, bounding the worst case to 32,640 comparisons.
The schema regression checks both sides of the boundary.
