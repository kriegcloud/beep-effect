# CSF-042: Departed terminal shells bypass retirement write detection

- Severity: Informational
- Codex ID: `commit:e171dcc69cc88191b01955cd694f8787`
- Source commit: `aec33cc4ab59bc26cc74d58bef723db430855496`
- Owner: Worktree retirement fence
- Status: confirmed; repair implemented

## Public Summary

Self-retirement allowed an initially idle desktop terminal shell to remain in
the lane during archive capture. The final safety scan checked only shells
still attached to the directory; a shell that wrote and then changed directory
or exited could disappear from that scan, allowing an uncaptured write to be
deleted.

## Current-HEAD Validation

Verdict: confirmed at current HEAD. The second scan built its PID list from
current attachments only and omitted the first scan's exempted PID set.

## Remediation

Before deleting the fenced checkout, recheck the context-switch count for
every initially exempted terminal shell, independent of the current
attachment list. An unreadable, departed, or changed shell preserves the
fenced copy and reports an incomplete archive.
