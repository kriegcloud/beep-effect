# CSF-034: Crafted PDF font graphs cause exponential validation work

- Severity: Informational
- Codex ID: `commit:8eb075ce10548191a41c04ca6d554955`
- Source commit: `b79308975cdc18b24c90c2938c7755df43c9e131`
- Owner: PDF font structure inspector
- Status: confirmed; repair implemented

## Public Summary

Shared descendant font dictionaries caused exponential recursion in PDF structure inspection when none contained an embedded font.

## Current-HEAD Validation

Verdict: confirmed at current HEAD. The current inspector recursively revisited the same PDFDict for each repeated DescendantFonts edge and had no cycle or traversal limit. The attack can be reached by a crafted PDF submitted for drawing validation.

## Remediation

Memoize embedded results by PDF dictionary identity, reject cycles, and cap distinct node visits and depth. A generated PDF regression uses a deep shared graph; another checks a cycle.
