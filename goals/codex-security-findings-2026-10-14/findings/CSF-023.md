# CSF-023: Intake inspector can leak document bytes to the hosted relay

- Severity: Informational
- Codex ID: `commit:2eb31145cfd88191a526b40de0ff6d7d`
- Source commit: `6cbe90d5c1a990c26084e7ca97d760d746106bc5`
- Owner: Stately inspector event projection
- Status: confirmed; repair implemented

## Public Summary

The development inspector forwarded complete statechart events to a relay.
An invoked file-read actor's completion event can contain selected document
bytes even though its snapshot context projection omits those bytes.

## Current-HEAD Validation

Verdict: confirmed at current HEAD for the event forwarding defect. The
inspector passed `event.event` unchanged to both SDK calls. Whether a specific
child completion reached the hosted relay was not established by the report;
the shared forwarding path nevertheless allowed arbitrary event payloads.

## Remediation

Project every forwarded event to its type string, omitting all payload fields.
The SDK transport regression sends an event with a marker and verifies that
the marker is absent from serialized messages while transition states remain
visible. Update the runbook's disclosure description.
