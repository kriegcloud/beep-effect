## Public Summary

Review round output paths were joined below a validated matter directory, but intermediate directories and destination files could be symlinks. A planted inventory.json link could redirect an ingest or plan write outside the corpus.

## Current-HEAD Validation

Verdict: confirmed at current HEAD. Current HEAD used ordinary writeFile on each round output after validating only the matter directory. The focused tests exercise a linked review directory and a linked inventory leaf.

## Remediation

Create review directories through no-follow directory descriptors, verify the bound directory remains under the corpus root, and atomically replace each round file through its bound parent. A symlink leaf is replaced without writing its target.
