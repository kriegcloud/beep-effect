# CSF-041: Unnormalized sensitivity labels bypass memory access checks

- Severity: Informational
- Codex ID: `commit:dc5e336a334c8191a21a40d7505b65fb`
- Source commit: `5c768538e434336885d324cbf56d04fc2684959b`
- Owner: scratchpad memory access policy
- Status: confirmed; repair implemented

## Public Summary

Memory access checks compared stored sensitivity labels with lowercase
restricted labels exactly. Raw schema and overlay paths could preserve labels
with mixed case or surrounding whitespace, causing restricted content to pass
the sensitivity check.

## Current-HEAD Validation

Verdict: confirmed at current HEAD. `MemoryItem` accepts arbitrary strings and
`basePolicyChecks` performed exact membership without canonicalization, while
the optional normalization helper was not used on every input path.

## Remediation

Normalize each label at the shared policy decision point before restricted
membership. A regression decodes raw unnormalized models and proves default
and archive access deny them.
