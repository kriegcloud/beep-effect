# CSF-026: Event deletion permits traversal to other Graph resources

- Severity: Informational
- Codex ID: `commit:5455745324c88191b9fca68421e0ab42`
- Source commit: `6081174d05f7d0923c0034b358f6cbf8be365ac0`
- Owner: M365 Graph path segment schema
- Status: confirmed; repair implemented

## Public Summary

The Graph event-delete API interpolated a validated event ID into an
authenticated DELETE URL. Its path-segment schema accepted backslashes and
control characters that WHATWG URL parsing can turn into traversal.

## Current-HEAD Validation

Verdict: confirmed at current HEAD. The public service method remained
reachable to in-process consumers, although the current MCP toolkit does not
expose deletion. A tab/backslash payload passed the old schema and normalized
to a message resource under the mailbox. Graph authorization still applies.

## Remediation

Reject backslashes, URL query and fragment delimiters, and ASCII controls
in the shared Graph path-segment schema, retaining the existing slash, dot-dot,
and percent checks.

Changed files:

- `packages/drivers/m365/src/M365.service.ts`
- `packages/drivers/m365/test/M365.write.test.ts`
