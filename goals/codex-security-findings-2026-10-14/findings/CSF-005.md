# CSF-005: Boundary\-date emails can crash the docket intake service

- Severity: Medium
- Codex ID: `commit:d4f610bfa9c88191942cbaf48ca19cfb`
- Source commit: `a9b6f6cc48255d51f78fe51fa6418faa061e27fa`
- Owner: docket Graph calendar adapter
- Status: confirmed; repair implemented

## Public Summary

A message-derived deadline of `9999-12-31` is a valid LocalDate, but an Outlook
all-day event needs the following day as its exclusive end. Constructing that
end throws outside the typed Graph error channel, so the docket poll can stop
before recording the offending message's attempt or advancing its cursor.

## Current-HEAD Validation

Verdict: confirmed conditional vulnerability at current HEAD. Security Cloud
traced the model output through the Graph adapter, and the adapter still called
the unchecked all-day-window helper. Exploitability depends on the model
extracting and accepting the supplied date; live model timing was not tested.

## Remediation

The Graph adapter now rejects a start date whose exclusive end is outside the
supported LocalDate range before any Graph request. It returns a typed calendar
error that the intake service converts to a persisted per-message failure,
allowing retry-budget handling and later messages to proceed.
