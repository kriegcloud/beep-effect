# CSF-030: Quadratic regex permits denial of service in OA recognition

- Severity: Informational
- Codex ID: `commit:658f385178a08191a050ad0a5c518261`
- Source commit: `5bb194eba8b2dc3cf85e998c5b48abd2300caf3c`
- Owner: office action text recognizer
- Status: confirmed; repair implemented

## Public Summary

A repeated statutory-period marker without a terminator caused the Uncovered schema predicate to rescan suffixes with a quadratic regular expression.

## Current-HEAD Validation

Verdict: confirmed at current HEAD. The current recognizer passed document-controlled text to an unanchored regex whose lazy suffix search restarted at each marker. Repeated incomplete markers forced quadratic work.

## Remediation

Split text once at period boundaries and check each disjoint segment with direct substring searches. The regression covers a long repeated-marker input and the supported ELEVEN terminator.
