- Codex ID: `commit:d29a8fc22b6c8191ab54af2d30fbea8c`

## Public Summary

The resume path followed a planted symlink in the corpus output tree. Before
checking the source manifest, staging cleanup could remove a redirected
directory's `.staging` contents; later publication could replace its fixed
artifact names.

## Current-HEAD Validation

Verdict: confirmed at current HEAD. The non-overwrite path retained an existing
output entry and recursively removed its staging child without checking whether
the output or its ancestors were symbolic links.

## Remediation

Reject symbolic links in the extract output components before acquiring the
run lock, before output preparation, and after directory creation. A focused
test plants the default output link and proves its target sentinel remains
unchanged and no lock is created.
