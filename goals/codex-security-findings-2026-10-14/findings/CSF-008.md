# CSF-008: Job\-log ANSI filter can reconstruct terminal control sequences

- Severity: Low
- Codex ID: `commit:220ff6218bdc819183439be00a008360`
- Source commit: `21813b5cbab3057a624ef41e4ec4e819003449ab`
- Owner: gh-fix-ci job-log inspector
- Status: confirmed; repair implemented

## Public Summary

The inspector removes ANSI sequences from untrusted CI job logs in one pass.
A malformed OSC sequence with an embedded CSI sequence can become a valid
terminal control after the inner CSI is removed, and the default text renderer
would print it literally. The demonstrated payload is an OSC 52 clipboard
write under terminals that support it.

## Current-HEAD Validation

Verdict: confirmed sanitizer flaw at current HEAD. Security Cloud validation
traced the job-log fallback and reproduced the nested escape transform through
the inspector with stubbed log bytes. Live GitHub byte preservation and
terminal clipboard mutation were not established; the tested older `gh` build
also rejected the escape-sequence flag.

## Remediation

The inspector now removes residual C0 and C1 terminal control characters after
ANSI substitution, preserving only tab and newline. Removing the escape and
terminator characters makes any newly joined sequence inert before rendering.
