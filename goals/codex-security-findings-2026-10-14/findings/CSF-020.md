# CSF-020: Adoption writes outside the packet through directory symlinks

- Severity: Informational
- Codex ID: `commit:13f1a8e11b848191bbdeb43201ba2837`
- Source commit: `5ae1dd96d0160ed445c286edf3a2bbfc7f4eb4b2`
- Owner: goal adoption materializer
- Status: confirmed; repair implemented

## Public Summary

A reviewed adoption plan could create generated files outside the packet through a symlinked ancestor. The plan digest did not bind directory identity.

## Current-HEAD Validation

Verdict: confirmed at current HEAD. A packet ops symlink to an external writable directory would be followed by recursive parent creation and exclusive file creation. The final wx flag prevented overwrite but not external creation.

## Remediation

Route exclusive creation through the shared symlink-free contained filesystem guard. The helper creates missing parents component by component, rejects links and escapes, rechecks containment, and retains wx.
