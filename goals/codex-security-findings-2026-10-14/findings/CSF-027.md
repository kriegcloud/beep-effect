# CSF-027: Bootstrap executes unverified op during status logging

- Severity: Informational
- Codex ID: `commit:5d581e268758819189f854ccaba1ca54`
- Source commit: `b877057bc49dca15be45cc7c494e6c9326e5cc92`
- Owner: cloud bootstrap 1Password status
- Status: confirmed; repair implemented

## Public Summary

The bootstrap verified a downloaded 1Password CLI but ran an unqualified op command for final status. A pre-existing PATH executable could run after verification failed or shadow the installed binary.

## Current-HEAD Validation

Verdict: confirmed at current HEAD. The current bootstrap script executed op from PATH unconditionally, including after a verification failure. This could run an unverified executable inherited from a reused environment.

## Remediation

Record the absolute destination only after a verified install and query that exact path for status. Report missing without invoking any PATH op when verification or installation did not succeed.
