# CSF-043: Size\-only Box conflicts can falsely complete pending filings

- Severity: Informational
- Codex ID: `commit:ed9c99bbe3c88191abc106dc70ed75be`
- Source commit: `8f74b33631e1f949ea8bcbd94c1f660f578e201e`
- Owner: Mail attachment filing reconciliation
- Status: confirmed; repair implemented

## Public Summary

A pending Box upload could be marked complete against an existing conflicting file when only its byte length matched the intended attachment. That does not prove the existing file contains the intended bytes.

## Current-HEAD Validation

Verdict: confirmed at current HEAD. The current use case adopted a conflict by equal size when SHA-1 metadata was absent. The production adapter can forward size independently from hash, making the conditional path reachable.

## Remediation

Require a matching content hash to adopt an existing file; otherwise retire the pending intent and upload under the short-hash alternate name. The size-only regression now expects that fallback.
