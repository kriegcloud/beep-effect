# CSF-033: New Bash grants bypass the Beep\-only log access restriction

- Severity: Informational
- Codex ID: `commit:8b61b0e4c7608191874a62ddb11eab25`
- Source commit: `153a4500844d9d259d0d74475a191080acf9ff58`
- Owner: Claude Bash permission allowlist
- Status: confirmed; repair implemented

## Public Summary

Two broad systemctl and journalctl grants appeared to scope access to Beep units, but accepted additional unit arguments that could select unrelated user logs.

## Current-HEAD Validation

Verdict: confirmed at current HEAD. The current checked-in settings and ai-sync allow domain contained both raw prefix grants. Repeated journalctl -u selectors combine as an OR filter, so the Beep prefix did not confine later arguments.

## Remediation

Remove the two unsafe automatic grants from checked-in settings and the exact ai-sync allow domain. The read-only list-timers grant remains. A constrained wrapper can be added separately if log access is needed.
