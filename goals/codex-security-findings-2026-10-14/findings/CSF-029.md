# CSF-029: Model report symlinks can overwrite operator files

- Severity: Informational
- Codex ID: `commit:6508654b804081919addeed48402cc6a`
- Source commit: `ae35cf909cf42dd2620a721fc21d395b95348e43`
- Owner: models report writer
- Status: confirmed; repair implemented

## Public Summary

The operator-selected report directory could contain predictable report-name symlinks. Writing reports followed those links and replaced operator files outside the report directory.

## Current-HEAD Validation

Verdict: confirmed at current HEAD. The current command wrote both reports with ordinary writeFileString after creating the directory. Existing final-component symlinks were followed even when the model check later reported drift.

## Remediation

Use the shared contained atomic writer for each report. It rejects symlink destinations and symlinked path entries and never truncates a linked target.

- `packages/tooling/tool/cli/src/commands/Models/Models.command.ts`
- `packages/tooling/tool/cli/test/models-init-command.test.ts`
