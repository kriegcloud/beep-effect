# CSF-035: Historical citations cause unbounded repository archive copies

- Severity: Informational
- Codex ID: `commit:9061a23fb8708191b797a2c1d16a44c5`
- Source commit: `319436049eec0e08a36aae46d6ebf5e15a7d4d01`
- Owner: Knowledge doctor historical citations
- Status: confirmed; repair implemented

## Public Summary

A Markdown report could cite many distinct historical commits. The doctor materialized one full repository archive per commit and retained each expanded tree for the scan, allowing an unbounded local disk and memory cost.

## Current-HEAD Validation

Verdict: confirmed at current HEAD. Current HEAD accepts every unique commit marker in one report and calls the historical tree materializer for each. A focused test exercises five distinct historical markers.

## Remediation

Reject a report with more than four distinct historical commits before ancestry resolution and delete each compressed archive immediately after extraction. The limit is per report and can be revisited with a bounded streaming design.
