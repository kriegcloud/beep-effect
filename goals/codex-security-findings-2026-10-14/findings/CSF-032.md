# CSF-032: Boundary\-date input can repeatedly abort docket intake polls

- Severity: Informational
- Codex ID: `commit:75b44d0da8f88191ae3ae1bc4ff38ea6`
- Source commit: `793b1efffb26a55f67bc64d49632a9089df4ab26`
- Owner: docket reminder ladder
- Status: confirmed; repair implemented

## Public Summary

A valid year-one stated deadline causes the reminder ladder to subtract its
offsets before it discards past reminders. The first subtraction crosses into
year zero, where LocalDate construction throws as an Effect defect. The docket
poll can retry the same message without recording an attempt.

## Current-HEAD Validation

Verdict: confirmed for the current docket policy. Security Cloud validation
traced the boundary arithmetic and poll propagation; the current ladder still
subtracted offsets before filtering. The production mailbox and agent adapter
now exist, though specific model extraction of the crafted date is untested.

## Remediation

The ladder now computes the distance to the due date and filters offsets that
cannot yield a future reminder before subtracting. Past and near deadlines
produce no rungs and report truncation without constructing out-of-range dates.
