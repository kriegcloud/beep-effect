The rule labels 647 sites "Same runtime behavior" (`slice`, `includes`,
`endsWith`, `startsWith`, `trim`, `toLowerCase`, `padStart`, `trimEnd`,
`toUpperCase` and a few singles). The other 766 change shape and need a reviewed
rewrite, not a find-and-replace:

- `indexOf`, `lastIndexOf`, `charCodeAt`, `codePointAt`, `at` return `Option`
  where native returns `-1`, `NaN` or `undefined`.
- `split` returns a `NonEmptyArray`; `"".split("")` gives `[""]`, not `[]`, and
  there is no `limit`.
- `replace` and `replaceAll` accept only a string replacement, not a callback.
- `repeat`, `match`, `matchAll` and `search` carry their own notes in the rule text.
