# Cache baseline review: 3-A9

Reviewed 2026-10-23 for adoption PR 3-A9 of `goals/effected-promotion`
(reuse site #137: observability `catalog/Catalog.names.ts` `PackageName` onto
`@beep/package-json` `ScopedPackageName`).

`bun run beep quality cache-policy` reported 7 blocking findings and one
review-level source drift, all introduced by this branch:

- Configuration drift on `@beep/observability` (`#build`, `#check`,
  `#doctest`, `#lint:deprecated-apis`, `#test`, `#test:property`). Each
  drifted tuple follows from the one new `@beep/package-json` workspace
  dependency in its manifest; no command, input, output or cache flag changed.
- Root (`//`) drift on `//#lint:policy-fingerprint`, with the matching
  `turbo.json` source drift. `bun run beep lint policy-fingerprint --write`
  added the `package.json` and `src/**` globs of `@beep/npm-spec` and
  `@beep/package-json` to the task inputs and to
  `standards/policy-tools.fingerprint.json`, because `@beep/repo-cli` reaches
  them through `@beep/observability` now. No other root task changed.

The architecture ceiling allows the edge: `foundation/capability` may depend
on `primitive`, `modeling` and `capability` (`standards/ARCHITECTURE.md`), and
`@beep/package-json`'s own closure (`@beep/identity`, `@beep/jsonc`,
`@beep/npm-spec`, `@beep/semver`, `@beep/spdx`) does not reach
`@beep/observability`, so there is no cycle. Nothing new enters `bun.lock`
beyond the workspace edge.

## Turbo coupling, measured against current main

Measured from the workspace `dependencies` closures at `origin/main`
8b47e722ee and at this branch head. `@beep/observability`'s closure grows from
6 to 11 workspaces (`@beep/jsonc`, `@beep/npm-spec`, `@beep/package-json`,
`@beep/semver`, `@beep/spdx`). 23 workspaces gain `@beep/package-json` in
their closure through `@beep/observability`; `@beep/repo-cli` gains only
`@beep/npm-spec` and `@beep/package-json` (it already reached the others).
An edit to `@beep/package-json/src/**` or to one of its four new closure
members now invalidates those workspaces' `#build`, `#check` and `#test`
cache entries.

The runtime import is the one leaf `@beep/package-json/PackageName`, whose
imports are `@beep/identity/packages` and `effect`, so no manifest, file IO or
grammar code reaches observability at runtime. The coupling is the Turbo
workspace-level hash only. It is accepted: `@beep/package-json` is the one
owner of npm name rules (W3-f), and `@beep/npm-spec`, `@beep/semver` and
`@beep/spdx` were promoted as stable modeling packages with low churn.
